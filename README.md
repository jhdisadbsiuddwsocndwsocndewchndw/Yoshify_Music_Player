# Yoshify Offline Music Player

Yoshify is an offline music player made using Python. The purpose of Yoshify is to allow users to listen to music offline through a simple and easy-to-use GUI.

# Features

- Login and sign-up system
- Stores user login information using an SQLite database
- Plays music offline
- Play and pause button
- Skip to the next song
- Go back to the previous song
- Volume slider
- Displays the current song title and artist
- Songs loop from the last song back to the first song
- Tkinter graphical user interface

# Technologies Used

- Python
- Tkinter - used to create the GUI
- SQLite - used to store user login information
- VLC - used to play and control the music
- PIL / Pillow - used to display images

# How Yoshify Works

When Yoshify starts, the user is shown a login and sign-up screen.

A new user can create an account by entering a username and password. Their information is stored in the SQLite database.

An existing user can enter their username and password to log in. If the details are correct, Yoshify opens the music player.

The music player allows the user to play/pause music, skip songs, go back to previous songs and change the volume.

# How to Run

1. Download the Yoshify project folder.
2. Make sure Python is installed.
3. Install the required libraries such as VLC and Pillow.
4. Make sure the songs and image files are inside the correct project folders.
5. Run the login Python file.
6. Login or create an account to access the music player.
